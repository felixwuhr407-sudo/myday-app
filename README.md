# MyDay — Persönlicher Organizer

Ein dunkles Dashboard mit blauen Akzenten für Aufgaben, Schule, Termine und Ideen.

## Starten auf Windows
1. Entpacke den Projektordner.
2. Öffne den Ordner in Visual Studio Code.
3. Öffne `index.html` im Browser oder starte Live Server über **Go Live**.

## Dateien
- `index.html` — Struktur und Bereiche
- `style.css` — dunkles, responsives Design
- `script.js` — Funktionen und lokale Speicherung

## Hinweise
- Die Daten werden im lokalen Speicher des verwendeten Browsers gespeichert.
- Die Daten werden nicht automatisch zwischen Surface und Handy synchronisiert.
- In den Einstellungen kannst du Daten als JSON exportieren und später importieren.
- Beim Löschen oder Importieren fragt die App zur Bestätigung nach.
